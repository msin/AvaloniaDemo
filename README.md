# AvaloniaDemo

A demo project built with [Avalonia UI](https://avaloniaui.net/) - a cross-platform .NET UI framework.

## Getting Started

### Prerequisites

- [.NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) or later

### Building

```bash
dotnet build
```

### Running

```bash
dotnet run
```
